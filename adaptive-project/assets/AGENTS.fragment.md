# 自适应项目接入

此片段供合并到项目AGENTS.md，保留已有规则，不授予新的外部权限。

用户要求使用adaptive-project执行项目时，读取已安装技能或用户提供的SKILL.md。通过scripts/runtime.py访问原项目.adaptive-v4/state.sqlite3；不直接改写数据库，不初始化重复项目。新项目绑定真实目标、授权、验收、写入范围和有限预算。

在已授权范围内主动委派独立子任务，按实际需要创建、调整或休眠职责。执行者以自身身份领取，只写本次隔离尝试，通过运行时提交并返回证据、限制和候选记忆；遵守宿主并发与项目额度。

恢复先核对原授权、控制、预算、绑定、有效凭据和未知派发。暂停不自行解除，额度不重置。长期聊天和后台计划须满足真实授权及工具要求；收尾先关闭业务准入，再prepare、暂停核验、confirm，最后必要时删除。

只要求设计、解释或审阅时不启动项目。
