# Codex 宿主适配

skill定义流程，runtime.py保存事务，Codex工具执行模型、子代理、聊天和计划操作。安装包不会提供常驻模型服务或新增宿主工具。

| 功能 | 目标要求 | 缺失时 |
| --- | --- | --- |
| 任务、探索、记忆、预算和检查点 | Python 3.8+与本地文件访问 | 只做设计并说明缺口 |
| 并行执行 | 实际子代理工具及额度 | 前台顺序执行 |
| 长期职责聊天 | 创建、读取、派发和等待工具及授权 | 使用逻辑职责和可用代理 |
| 自动唤醒 | 原生计划、绑定、状态核验及暂停/删除工具 | 保持前台 |

安装后运行doctor.py，协调者核实实际工具、参数、权限与并发额度。文档中的示例和其他设备绑定不是当前能力。文件复制、hash核验与宿主发现分别验证，见 [安装](portability.md)。

职责不必对应侧栏聊天。短期工作使用当前会话或子代理；稳定工作量才创建已授权长期职责聊天，先查重复职责、休眠绑定、outbox与容量。适用项目指令可指导子代理，但不能替代长期聊天工具要求的用户授权。

长期聊天按 [会话协议](long-lived-chats.md)，后台按 [引导](bootstrap.md)。保存真实回执，核验协调载体登记，不靠增大上限解决未确认创建。模板措辞本身不授予后台或外部权限。

完整技能安装到目标支持目录后，真实项目通过runtime.py初始化。assets/AGENTS.fragment.md供合并到现有项目指令，保留原规则。不要复制早期空状态模板。

项目内知识以有来源记录维护，不依赖或编辑Codex内部自动记忆。目标、授权、数据库和证据决定行动，跨项目传播须核实范围。

官方参考：[技能](https://learn.chatgpt.com/docs/build-skills)、[项目指令](https://learn.chatgpt.com/docs/agent-configuration/agents-md)、[子代理](https://learn.chatgpt.com/docs/agent-configuration/subagents)。实际能力以当前宿主为准。
