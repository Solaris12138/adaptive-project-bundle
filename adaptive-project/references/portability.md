# 新设备安装与能力适配

这是可独立安装的 skill。使用技能所在目录解析 scripts/ 与 references/，项目目录来自用户当前工作区；不依赖开发者目录、Python 绝对路径、历史聊天或计划 ID。Python 脚本只需 Python 3.8+ 标准库。可选 windows_task.ps1 仅在 Windows 上使用 PowerShell 5.1+ 和 Task Scheduler COM；它不改变其他平台的前台/原生调度能力。

安装或迁移到新宿主后：
1. 用可用 Python 运行本技能 scripts/doctor.py；可选择在新的临时项目目录运行 --smoke。纯 Python 诊断不能发现 Codex 工具，host_capabilities=not_probed 不表示不可用或已经可用。
2. 协调者查看当前实际工具和权限，分别登记子代理、长期聊天、原生调度是否可用。只在能力存在且用户已授权时使用；缺少长期聊天时采用逻辑职责单元，缺少调度时使用前台模式。若缺失能力是用户硬性要求，明确阻塞点。
3. 按当前工具契约核实创建/派发权限、并发额度、计划目标与暂停/删除要求，不复用文档中的历史环境额度。不能靠安装脚本创建或授予宿主工具能力。
4. 新项目按正常引导创建真实授权、有限预算和章程。保留任务事务、实体版本、租约、outbox、正式记忆及分阶段验收规则。

发布包根目录 README.md 提供安装器和指令模板；直接复制完整技能目录到目标支持的 skills 目录也可使用。运行 scripts/doctor.py 是本地依赖检查，宿主能发现并读取本技能应在新会话单独确认。

本包迁移功能，不自动迁移活动项目。不要随包复制个人账户、试运行证据、数据库或聊天/计划绑定。项目数据仍保存在各项目的 .adaptive* 目录。对既有项目迁移的请求应先停止原写入和调度，再单独设计数据/路径/授权/宿主绑定迁移并核验；没有自动迁移命令。不要把安装技能解释成恢复旧项目、解除暂停或重置额度。
