# Adaptive Project — 正式发布 skill

将 adaptive-project.zip 复制到另一台设备并解压，进入 adaptive-project-bundle 目录。此包提供主动探索、候选验证、职责调整、任务领取与冲突处理、项目记忆、检查点恢复、有限预算和严格收尾。核心为 Python 标准库运行时；无需 pip、Node、API key 或原开发工作区。模型执行使用目标设备上的 Codex 及其现有账户。

## 安装（Windows / macOS / Linux）

需要 Python 3.8+（含 sqlite3）以及可读写本地项目文件的 Codex。Windows 通常使用 python；macOS/Linux 如果只有 python3，替换下面的命令名。先在解压出的发布目录打开终端：

```sh
python -B -X utf8 install.py verify
python -B -X utf8 install.py install
```

默认安装至当前用户的 ~/.agents/skills/adaptive-project。安装器不覆盖不同版本；相同内容可重复安装。若已存在不同版本，先将旧技能完整备份到技能发现目录以外，再安装；项目数据库应保存在项目目录，不放进技能目录。

只对单个项目安装，或宿主要求其他目录时：

```sh
python -B -X utf8 install.py install --skills-dir "/absolute/project/.agents/skills"
```

路径参数是父级 skills 目录。不要同时在多个发现位置安装同名技能。安装器验证整个发布目录，不要把试运行输出放到发布目录里；SHA256SUMS.json 用于完整性校验，不是发行者数字签名。

## 在新设备上验收

在 Codex 新会话中输入下面这段话：

> 使用 $adaptive-project。先定位已安装技能，运行 scripts/doctor.py；检查当前宿主是否支持子代理、长期职责会话和原生定时调度，报告可用模式。先不要创建后台计划。

若无法识别，重新打开 Codex 后再检查技能列表。文件复制成功与宿主发现成功需要分别确认。

也可直接测试脚本。以下路径替换为安装器返回的 destination：

```sh
python -B -X utf8 "/absolute/skill/adaptive-project/scripts/doctor.py"
python -B -X utf8 "/absolute/skill/adaptive-project/scripts/doctor.py" --smoke "/absolute/projects/new-portable-demo"
```

smoke 的父目录必须存在、目标目录必须不存在。它只创建本地合成任务并验收和审计，不调用模型、不建立聊天或计划，不代表真实多代理端到端验证。无需重装依赖即可调用全部脚本。

## 开始真实项目

在目标项目目录打开 Codex，用真实数值替换方括号内容：

> 使用 $adaptive-project 完成：[模糊目标]。交付标准：[要求]。允许在本项目内自主探索、创建和调整职责单元、委派子代理、维护记忆。探索最多 [3] 个候选、[4] 次验证、[6] 个预先定义的成本单位；最多 [8] 次任务领取，截止 [具体日期时间及时区]。先探测宿主能力并登记章程，按证据调整方向，最终交付成果、证据和未解决问题。

若还需要长期职责会话和后台推进，在同一请求中明确补充：

> 允许为本项目按需创建和协调最多 [3] 个长期职责会话，并配置原生自动唤醒；最多 [6] 次工作唤醒、[4] 次派发，截止 [具体时间]。先核验宿主支持并登记实际绑定；结束时关闭业务准入、prepare、暂停核验、confirm，最后删除本项目计划。

以上是用户可修改的指令模板，不是随安装自动生效的授权。先判断是否需要并行职责，不强制每个项目设立固定“部门”。配额为工作次数与时间范围，不是精确 token/金额硬上限。

## 能力与迁移范围

| 功能 | 目标环境要求 |
| --- | --- |
| 探索、任务、记忆、冲突、预算、检查点 | Python + 本地文件访问 + Codex |
| 多代理执行 | Codex 实际提供且允许使用的子代理工具 |
| 长期职责会话 | 实际可用的会话创建、读取、派发和等待工具，以及相应授权 |
| 原生自动唤醒 | 实际可用的计划工具与目标聊天绑定，以及后台授权 |
| 缺少上述宿主工具 | 继续使用前台、逻辑职责单元；缺失能力明确报告，不声称后台已启用 |

此包迁移的是完整功能，安装时不迁移正在运行的项目、聊天 ID、登录凭据、计划 ID 或本机任务计划程序。数据库多设备并发共享及自动跨设备续接未实现。搬迁既有项目需另行处理原宿主停用、静止数据复制、授权和路径检查及新宿主绑定，不能将旧绑定直接当作新设备有效授权。

本次不包含退出应用、关机或开机任务的辅助程序。已有检查点恢复和收尾协议仍随 skill 提供。

## 验证范围与维护

包采用平台无关 Python 和路径定位；当前发布只在 Windows 的隔离目录完成实测，macOS/Linux 需要在目标设备运行 doctor 和 smoke。长期聊天、调度工具的具体名称与格式按实际宿主探测，不承诺所有 Codex 发行形态均提供相同能力。

所有发布文件名保持稳定，发布编号只记录在 SHA256SUMS.json 的version元数据中。包内仅含当前统一运行时，旧开发实现与试运行证据不随包分发。只分发技能和安装器，无试验数据库、用户资料或个人路径配置。维护者可从源码 packaging/build_portable.py 重建发布包。

安装路径与发现方式依据 [官方技能文档](https://learn.chatgpt.com/docs/build-skills)（2026-11-11 核对）。这是可本地安装的独立 skill 包；未作为插件提交或发布到目录。
